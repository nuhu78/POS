# POS Frontend

React 18/19 + Vite SPA for the Family POS system (furniture & gift shop).

See the root [`../README.md`](../README.md) for the full project story, setup, and demo access.

## Local dev

```bash
npm install
npm run dev
```

Point it at the Django API via `VITE_API_BASE_URL` (defaults to `http://localhost:8000/api/v1`).
